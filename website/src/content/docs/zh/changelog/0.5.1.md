# CubePod 0.5.1

## 功能与改进

- **E2B PTY、`WatchDir` 与 RWX Volume 挂载（[CEP-0026](/zh/ceps/0026-k8s-kata-e2b-volumes/)）。** 新增官方 E2B PTY 创建、I/O、终端大小调整、重连与终止（`#65`），支持 `files.watch_dir` / `WatchDir` 目录事件流（`#66`），并实现 Volume API、卷内容读写以及 Kubernetes Kata RWX 卷挂载（`#67`、`#70`）。
- **E2B Secrets API 与零信任 Vault 集成（[CEP-0027](/zh/ceps/0027-e2b-secrets-api/)）。** 实现 `/secrets` 增删改查接口与零信任凭据托管集成（`#73`），使官方 E2B SDK 无需将明文密钥注入沙箱即可管理密钥。
- **沙箱生命周期事件与签名 Webhook（[CEP-0028](/zh/ceps/0028-sandbox-events-and-webhooks/)）。** 新增沙箱生命周期事件流与 HMAC 签名 Webhook 投递（`#78`），引入 `SandboxWebhook` CRD（`cubepod.io_sandboxwebhooks.yaml`）并扩展 `PodBox` CRD 字段。
- **E2B 兼容指南与 `cubepod.dev` 文档站。** 上线 [E2B 兼容性指南](/zh/getting-started/e2b-compatibility/)，将 secrets、webhooks 与 events 的 OpenAPI 标签与摘要与 E2B 对齐，将文档站域名迁移至 `https://cubepod.dev/`，并在 CI 中接入 `make test-e2b-compat`。

## 问题修复

- **官方 E2B 2.64.0 SDK 报文格式与模板标签对齐。** 将 `/v2/sandboxes` 与 `/secrets` 报文格式与官方 E2B 2.64.0 SDK 对齐（`#75`），为官方 E2B 模板标签接口返回 UUID 格式 `buildID`（`#76`），并修复 `files.write` 上传与 TypeScript `commands.run` 的 `exitCode` 返回问题（`#64`）。
- **临时 PVC 回收与 `podd` ConnectRPC `List`/`Stat`/`Remove`。** 修复 `kill()` 时未回收临时 PVC 的问题，并在 `crates/podd` 中补齐 ConnectRPC `List`、`Stat` 与 `Remove` 接口（`#68`）。
- **控制器 Pod 命名与镜像 `ENV HOME` 保留。** 移除控制器 Pod 名称中的 `-kata-pod` 后缀，并在 `crates/podd` 中保留基础镜像的 `ENV HOME` 环境变量（`#72`）。

## 升级前注意事项

`0.5.1` 新增了 `SandboxWebhook` CRD（`deploy/helm/cubepod/crds/cubepod.io_sandboxwebhooks.yaml`）并更新了 `PodBox` CRD（`deploy/helm/cubepod/crds/cubepod.io_podboxes.yaml`）。在执行 `helm upgrade` **之前**，请务必先应用最新 CRD 清单：

```bash
kubectl apply -f deploy/helm/cubepod/crds/
```

请按 [Kubernetes 与 Helm 部署指南](/zh/deployment/kubernetes-helm/) 将 `cubepod-controller`、`cubepod-gateway`、`cubepod-egress` 与 `cubepod-podd` 镜像及 Helm Chart 同步升级至 `v0.5.1`，并更新客户端 SDK（`pip install -U cubepod==0.5.1` / `npm install cubepod@0.5.1`）。
