# CubePod 0.4.0

## 功能与改进

- **兼容 E2B 的模板目录与 OCI 镜像构建（CEP-0019）。** 完整支持 `PodTemplate` 生命周期、兼容 E2B 的 `/templates` 目录接口、`cubepod template` CLI 与多语言 SDK 支持，以及 `cubepod-controller`（BuildKit）与本地 Docker 模板构建流水线。详见[沙箱模板目录与自定义构建](/zh/sdks/templates/)。
- **透明零信任出站代理与单 Pod mTLS 密钥生命周期（CEP-0020）。** 支持 TLS `ClientHello` SNI 检测、按需 Ephemeral CA HTTPS MITM `cpodref_` 占位符置换、白名单 DNS 解析、`iptables` 透明劫持，以及 `<box>-egress-mtls` / `<box>-egress-ca` Secret 的自动签发与回收。详见[零信任出站与凭据隔离](/zh/concepts/zero-trust-egress/)。
- **按需拉起的交互式桌面与签名 Panel 代理（CEP-0021）。** 新增 `cubepod-desktop` 镜像（Ubuntu 24.04、Xvfb、Openbox、Playwright Chromium CDP、x11vnc/noVNC、`ttyd`），仅在调用 `/sandboxes/{id}/desktop/start` 时按需启动，零冷启动开销，并打通签名 `/panel/{token}/` HTTP/WebSocket 代理路由。详见[桌面环境与签名 Panel 代理](/zh/concepts/desktop-and-panel-proxy/)。
- **崩溃一致的多代 CoW Fork 与无状态网关高可用（CEP-0022）。** 在 `podd` 中实现带看门狗的有界 `FIFREEZE`/`FITHAW` 冻结/解冻、本地 `cp --reflink=auto --sparse=always` 写时复制克隆、Kubernetes 多代 `<parent>-rootfs-gen<N>-pvc` `ForkFrom` 支持，以及基于 `PodBox` CRD 的无状态多副本 `cubepod-gateway` 高可用发现。详见[生命周期、预热池与 1s CoW 克隆](/zh/concepts/lifecycle-warmpool-fork/)。
- **多语言 Code Interpreter 内核与官方 Python / TypeScript SDK。** 为 `crates/podd` 新增运行于 `1000:1000` 非特权隔离下的 `python`、`bash`、`javascript`、`typescript`、`r`、`java` 有状态内核；发布 PyPI `cubepod` `0.4.0`（[Python SDK](/zh/sdks/python/)）与 npm `cubepod` `0.4.0`（[TypeScript SDK](/zh/sdks/typescript/)）；并完善 Kata Containers（`kata-qemu` / `kata-clh`）压测套件。

## 升级前注意事项

`0.4.0` 新增了 `PodTemplate` 及多项 `PodBox` 字段，执行 `helm upgrade` 前请先手动应用最新 CRD 清单：

```bash
kubectl apply -f deploy/helm/cubepod/crds/
```

请按照 [Kubernetes 与 Helm 部署指南](/zh/deployment/kubernetes-helm/) 将 `cubepod-controller`、`cubepod-gateway`、`cubepod-egress` 与 `cubepod-podd:v0.4.0` 同步升级。
