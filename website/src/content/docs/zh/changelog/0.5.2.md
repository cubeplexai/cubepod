# CubePod 0.5.2

## 功能与改进

- **补全 Helm Chart 参数接线（`#80`）。** 在 [Kubernetes 与 Helm 部署](/zh/deployment/kubernetes-helm/) Chart 中完整接入 `runtime.*`、`storage.*`、`egress.*`、`global.imagePullSecrets`、`runtime.templatePullSecret`、`gateway.livePodRouting` 与 `gateway.persistence` / `stateDir`，新增 `gateway-state-pvc.yaml` 模板，并支持通过 `egress.caSecretName` 与 `egress.upstreamCAEnabled` 向控制面挂载持久化 Egress CA Secret。
- **支持默认 Egress 镜像参数与 Gateway 拉取凭证（`#80`）。** 为 `cubepod-controller` 与 `cubepod-gateway` 新增 `--egress-image`（`CUBEPOD_EGRESS_IMAGE`）及 `controller.WithDefaultEgressImage`，并在 `cubepod-gateway` 补齐 `--image-pull-secrets`（`CUBEPOD_IMAGE_PULL_SECRETS`）。
- **本地 K8s 维护目录模板与 CRD 文档同步（`#80`）。** 新增 `deploy/k8s/local.example/` 作为可复现的 Helm 集群维护模板（配合 `.gitignore` 中的 `deploy/k8s/local/`），并将 `SandboxWebhook`（`cubepod.io_sandboxwebhooks.yaml`）纳入 CRD 自动生成文档。

## 问题修复

- **补齐 Helm `SandboxWebhook` RBAC 与 Gateway `CUBEPOD_STATE` 事件目录（`#80`）。** 在 `deploy/helm/cubepod/templates/rbac.yaml` 中补充 `sandboxwebhooks` 与 `sandboxwebhooks/status` 权限，并修复 `cubepod-gateway` 仅检查 `--state-dir` 而未识别 `CUBEPOD_STATE` 环境变量导致事件/Webhook 目录未启用的问题。

## 升级前注意事项

如从 `v0.5.0` 或更早版本升级，请在执行 `helm upgrade` **之前**先应用最新 CRD 清单：

```bash
kubectl apply -f deploy/helm/cubepod/crds/
```

请按 [Kubernetes 与 Helm 部署指南](/zh/deployment/kubernetes-helm/) 将 `cubepod-controller`、`cubepod-gateway`、`cubepod-egress` 与 `cubepod-podd` 镜像及 Helm Chart 同步升级至 `v0.5.2`，并更新客户端 SDK（`pip install -U cubepod==0.5.2` / `npm install cubepod@0.5.2`）。
