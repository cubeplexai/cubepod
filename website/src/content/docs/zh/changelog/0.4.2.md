# CubePod 0.4.2

## 功能与改进

- **E2B 风格 OpenAPI 接口分组与精简命名。** 将 [OpenAPI 规范](/openapi.yaml)按资源域划分为 `Sandboxes`、`Commands`、`Files`、`Desktop & Panels`、`Templates`、`WarmPools`、`System` 共 7 个分组，并将全部 52 个接口的 `summary` 精简为 2–4 个词的动作短名，同时把完整技术说明无损保留在 `description` 中。
- **交互式 API 控制台主题统一与明暗切换。** [交互式 API 控制台](/zh/api/) 同步集成文档站 `Oxide Copper` 深色与 `Light A` 浅色配色体系，内置 Dark/Light 快速切换按钮与单色品牌 SVG 标识。
- **CubePlex Agent 技术栈与脑手解耦架构展示升级。** 首页、[产品简介](/zh/getting-started/introduction/)与 README 新增 `CubePlex` → `CubeLoop` → `CubePod` 三层架构图与“脑手解耦（Brain-Hands Decoupling）”定位说明，并在 Hero 与 [Kubernetes 与 Helm 部署指南](/zh/deployment/kubernetes-helm/)中提供基于 GHCR OCI 的一键 `helm install` 安装命令。
- **跨仓库发版一致性校验与双语 Release Notes 自动生成。** 引入 `scripts/check-version-consistency.sh` 与 `scripts/release-notes.py`，在 CI 中自动校验 Rust、Go、OpenAPI、Helm、Python/TypeScript SDK 与双语日志的版本一致性。

## 问题修复

- **文档站细节与交互体验修复。** 修复侧边栏选中条目文字对比度不清与 Markdown 表格单元格左内边距过窄问题，对齐首页分栏标题，并修复生命周期演示日志样式作用域及 HTTP 环境下复制按钮剪贴板回退逻辑。

## 升级前注意事项

`0.4.2` 未变更 Kubernetes CRD 字段定义（若从 `0.4.0` 或更早版本升级，仍需先执行 `kubectl apply -f deploy/helm/cubepod/crds/`）。

请按 [Kubernetes 与 Helm 部署指南](/zh/deployment/kubernetes-helm/) 将 `cubepod-controller`、`cubepod-gateway`、`cubepod-egress` 与 `cubepod-podd` 同步升级至 `v0.4.2`，并更新客户端 SDK（`pip install -U cubepod` / `npm install cubepod@0.4.2`）。
