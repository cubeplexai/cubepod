# CubePod 0.7.1

## 功能与改进

- **完整 GHCR 镜像与清单发布及 CI 构建校验。** 在 `.github/workflows/ci.yml` 新增 `sandbox-images-ci` 任务，在 PR 与 `main` 推送时自动验证 `images/sandbox-base/Dockerfile` 与 `images/desktop/Dockerfile` 构建；并完整发布全部 6 个 GHCR 多架构镜像（`cubepod-podd`、`cubepod-controller`、`cubepod-gateway`、`cubepod-egress`、`cubepod-sandbox-base`、`cubepod-desktop`）以及 `release-manifest-v0.7.1.yaml`。

## 问题修复

- **修复 `cubepod-desktop` 镜像构建失败（`images/desktop/Dockerfile`）。** 补充安装 Playwright 内置 Node.js 驱动所需的 `libatomic1` 依赖，并为 `pip install --no-cache-dir --break-system-packages` 添加 `--ignore-installed` 参数，避免因 Ubuntu 24.04 Debian apt 预装的 `typing_extensions 4.10.0` 缺少 pip `RECORD` 文件导致卸载报错。

## 已知问题

- **Kata + Firecracker 块设备热插拔竞态问题（`#120`）。** 在 Kata Containers 搭配 Firecracker（`kata-fc`）运行时，沙箱 Pod 在业务容器启动前偶发因 `virtio-mmio` 块设备热插拔竞态导致 `EIO: I/O error`（`EXT4-fs (vdb): unable to read superblock`）并超时失败。详见 [issue #120](https://github.com/cubeplexai/cubepod/issues/120)。
- **Firecracker + E2B Volume 挂载持久化限制（`#122`）。** 由于 Kata Firecracker 不支持 `virtio-fs` 文件系统共享，目前基于宿主机目录拷贝（`ShareFile`）暂存的官方 E2B `volumeMounts` 在 `kata-fc` 上无法将 Guest 内的写入同步写回宿主机，沙箱销毁重建后数据不会保留。详见 [issue #122](https://github.com/cubeplexai/cubepod/issues/122)。
- **推荐默认使用 Cloud Hypervisor（`kata-clh`）。** 在 `#120` 与 `#122` 修复前，生产 Kubernetes Kata MicroVM 部署**推荐默认使用 Cloud Hypervisor（`kata-clh`）**。在 CI 中，`kata-clh` 流水线已完整通过官方 Python 与 TypeScript E2B SDK 全部测试场景且零跳过。

## 升级前注意事项

如从 `0.6.0` 或更早版本升级，执行 `helm upgrade` **之前**请务必先应用最新 CRD 清单（使 `SandboxWebhook` 获得 `status.deadLetters` 字段）：

```bash
kubectl apply -f deploy/helm/cubepod/crds/
```

从 `0.6.0` 或更早版本升级时，还请同时查阅 [0.7.0](/zh/changelog/0.7.0/) 与 [Kubernetes 与 Helm 部署指南](/zh/deployment/kubernetes-helm/) 中的 `0.7.x` 行为变更（`gateway.panelSecret` / `CUBEPOD_PANEL_SECRET` 启动校验、`featureGates.e2bTemplateAPI` 默认为 `true`，以及 Kata 推荐配置 `runtime.runtimeClassName: "kata-clh"`）。

请将 `cubepod-controller`、`cubepod-gateway`、`cubepod-egress`、`cubepod-podd`、`cubepod-sandbox-base` 与 `cubepod-desktop` 镜像及 `0.7.1` Helm Chart 同步升级，并更新客户端 SDK（`pip install -U cubepod==0.7.1` / `npm install cubepod@0.7.1`）。
