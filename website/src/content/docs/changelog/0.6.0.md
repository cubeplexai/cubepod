# CubePod 0.6.0

## Features and improvements

- **E2B Sandbox Metrics & Prometheus Observability ([CEP-0029](/ceps/0029-e2b-sandbox-metrics/), `#92`).** Added E2B-compatible `GET /sandboxes/{id}/metrics` and `GET /sandboxes/metrics` endpoints backed by in-guest `podd` sampling (`GET /metrics` and `GET /v1/prometheus`, including `podd-init` boot timings from `/run/cubepod/init-state.json`). Expanded Gateway (`:8080/metrics`), Controller (`:8081/metrics`), and Egress (`:19090/metrics`) with Prometheus metrics covering E2B request latency, CoW forks, WarmPool readiness, E2B volume mounts, secrets, panel sessions, desktop activations, events, webhooks, and egress decisions. See [API Overview](/reference/api-overview/).
- **Transparent Egress wiring & CSI `VolumeSnapshot` CoW fork mode (`#89`).** Wired `TransparentEgress` (`CUBEPOD_TRANSPARENT=1` + `NET_ADMIN`) and WarmPool egress secret handling into `cubepod-controller`, added `--fork-mode=snapshot` with `--volume-snapshot-class` (`snapshot.storage.k8s.io/v1` `VolumeSnapshot` cloning alongside `pvc-clone`), and added controller fork and WarmPool Prometheus metrics.
- **Multi-replica Secrets HA & strict per-pod mTLS exchange (`#90`).** Added `KubeSecretBackend` (`secrets.backend: "k8s"`) persisting AES-256-GCM encrypted E2B secrets in Kubernetes Secrets for stateless multi-replica Gateway HA, added HA Vault re-hydration (`Sync`), and enforced strict per-pod mTLS on `/internal/v1/egress/exchange` (`--egress-mtls-addr`).
- **Gateway concurrency, feature gates & async reaper events (`#91`).** Added per-sandbox operation locking (`lockSandboxOp`), TOCTOU-safe `SyncPodBoxesOnce` reconciliation, asynchronous idle reaper lifecycle events and webhook delivery, unified `--feature-gate` flags across Gateway and Controller, and E2B volume mount counters.
- **Optional Desktop WebRTC transport with noVNC fallback (`#95`).** Added `transport: "webrtc" | "novnc"` to `/sandboxes/{id}/desktop/start` (`images/desktop/cubepod-desktop-ctl` and `pkg/gateway/desktop.go`), returning `webrtcUrl`, `transportUsed`, and `fallbackReason` with automatic graceful fallback to noVNC. See [Interactive Desktop & Panel Proxy](/concepts/desktop-and-panel-proxy/).
- **Native Python & TypeScript SDK feature parity (`#95`).** Added sandbox metrics, write-only Secrets (`Secret.fill` / `fill_secret`), durable Volumes & content I/O, lifecycle Events & signed Webhooks, and Desktop `transport` options across both [Python SDK](/sdks/python/) and [TypeScript SDK](/sdks/typescript/).
- **Complete v0.6.0 Helm Chart wiring & Gateway PDB (`#95`).** Added `pdb.yaml` (`PodDisruptionBudget` automatically enabled when `gateway.replicaCount > 1`), `secrets-key-secret.yaml` and `secrets.*` configuration, `egress.transparent`, unified `featureGates.*` `--feature-gate` flags, and automatic RWX `e2bVolumes` + `K8sE2BVolumeMounts` activation when `e2bVolumes.rwxStorageClassName` is set. See [Kubernetes & Helm Deployment](/deployment/kubernetes-helm/).
- **TypeScript E2B compatibility suite, live K8s E2E tests & documentation (`#93`, `#94`, `#88`).** Added `test/e2b-compat-ts` (`make test-e2b-compat-ts`), extended Python E2B compatibility coverage, added live Kubernetes E2E lifecycle and WarmPool tests (`test/k8s-e2e/k8s_e2e_test.go`), updated bilingual website guides and CEP metadata, refreshed `og-banner.png`, and translated `docs/architecture.md` to English (preserving `docs/architecture_zh.md`).

## Fixes

- **Controller, Vault & Gateway edge-case hardening (`#89`, `#90`, `#91`, `#92`).** Hardened WarmPool egress secret lifecycle, `VolumeSnapshot` naming and build secret cleanup (`#89`); fixed Vault exchange/rotation races, composite fork keys, and `Store.Sync` locking (`#90`); prevented `SyncPodBoxesOnce` TOCTOU eviction (`#91`); and enforced metrics tenant isolation, bounded Prometheus label cardinality, ring buffer eviction, and CPU/loadavg guards (`#92`).

## Before upgrading

No Kubernetes CRD schema fields changed between `0.5.4` and `0.6.0`. If upgrading from `v0.5.0` or earlier, apply the latest CRDs **before** running `helm upgrade`:

```bash
kubectl apply -f deploy/helm/cubepod/crds/
```

Review the new `0.6.0` Helm Chart defaults in [Kubernetes & Helm Deployment](/deployment/kubernetes-helm/):
- `secrets.backend` defaults to `"k8s"` (requires an encryption key via `secrets.existingSecret`, `secrets.encryptionKey`, or `gateway.secretsKeySecret` when running multi-replica HA).
- `egress.transparent` and `featureGates.transparentEgress` are both `true` by default; both must be enabled for transparent `nftables`/DNS interception.
- Setting `e2bVolumes.rwxStorageClassName` now automatically enables `e2bVolumes` and `K8sE2BVolumeMounts`.

Upgrade `cubepod-controller`, `cubepod-gateway`, `cubepod-egress`, and `cubepod-podd` images together with the `0.6.0` Helm Chart, and update client SDKs (`pip install -U cubepod==0.6.0` / `npm install cubepod@0.6.0`).
