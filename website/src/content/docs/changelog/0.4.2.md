# CubePod 0.4.2

## Features and improvements

- **E2B-style OpenAPI taxonomy & concise sidebar labels.** Reorganized [`cubepod-v1.yaml`](/openapi.yaml) into 7 resource groups (`Sandboxes`, `Commands`, `Files`, `Desktop & Panels`, `Templates`, `WarmPools`, and `System`) and shortened all 52 operation `summary` titles to crisp action labels while preserving detailed explanations in `description`.
- **Interactive API Reference theme & dark/light sync.** Updated the [Interactive API Reference](/api/) (`ScalarApiPage`) to synchronize with Starlight's `Oxide Copper` dark and `Light A` themes, adding an inline Dark/Light toggle and unified monochrome brand SVG logos.
- **CubePlex Agent Stack & Brain-Hands Decoupling landing refresh.** Added the three-layer `CubePlex` → `CubeLoop` → `CubePod` stack diagram and Brain-Hands Decoupling narrative to the landing page, [Introduction](/getting-started/introduction/), and README, alongside a one-click `helm install` GHCR OCI quick-install command in the Hero and [Kubernetes & Helm guide](/deployment/kubernetes-helm/).
- **Automated release consistency & changelog validation.** Added `scripts/check-version-consistency.sh` and `scripts/release-notes.py` to enforce single-semver synchronization across Cargo, Go, OpenAPI, Helm charts, Python/TypeScript SDKs, and bilingual release notes in CI.

## Fixes

- **Documentation typography & UI polish.** Fixed active sidebar item text contrast in light and dark themes, increased Markdown table cell horizontal padding, aligned Hero dual-pane headers, fixed simulator log styling, and added an HTTP clipboard fallback for copy buttons.

## Before upgrading

No Kubernetes CRD schema fields changed in `0.4.2`. If upgrading from `0.4.0` or earlier, still apply the CRDs first (`kubectl apply -f deploy/helm/cubepod/crds/`).

Upgrade `cubepod-controller`, `cubepod-gateway`, `cubepod-egress`, and `cubepod-podd` together to `v0.4.2` via the [Kubernetes & Helm deployment guide](/deployment/kubernetes-helm/), and update client SDKs (`pip install -U cubepod` / `npm install cubepod@0.4.2`).
