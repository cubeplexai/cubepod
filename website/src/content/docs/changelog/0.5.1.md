# CubePod 0.5.1

## Features and improvements

- **E2B PTY, `WatchDir`, and RWX Volume mounts ([CEP-0026](/ceps/0026-k8s-kata-e2b-volumes/)).** Added official E2B PTY create, I/O, resize, reconnect, and kill (`#65`), `files.watch_dir` / `WatchDir` streaming (`#66`), and the Volume API with content operations and Kubernetes Kata RWX volume mounts (`#67`, `#70`).
- **E2B Secrets API & zero-trust vault integration ([CEP-0027](/ceps/0027-e2b-secrets-api/)).** Implemented `/secrets` CRUD endpoints and zero-trust vault integration (`#73`) so official E2B clients can manage secrets without exposing plaintext credentials inside sandboxes.
- **Sandbox lifecycle events & signed webhooks ([CEP-0028](/ceps/0028-sandbox-events-and-webhooks/)).** Added sandbox lifecycle event streaming and HMAC-signed webhook delivery (`#78`), introducing the `SandboxWebhook` CRD (`cubepod.io_sandboxwebhooks.yaml`) and webhook event fields on `PodBox`.
- **E2B Compatibility Guide & `cubepod.dev` docs site.** Published the [E2B Compatibility Guide](/getting-started/e2b-compatibility/), aligned OpenAPI tags and summaries for secrets, webhooks, and events with E2B, migrated docs to `https://cubepod.dev/`, and wired `make test-e2b-compat` into CI.

## Fixes

- **Official E2B 2.64.0 SDK wire-format & template tag alignment.** Aligned `/v2/sandboxes` and `/secrets` wire formats with the official E2B 2.64.0 SDK (`#75`), returned UUID `buildID` values for official E2B template tag APIs (`#76`), and fixed `files.write` uploads and TypeScript `commands.run` `exitCode` handling (`#64`).
- **Ephemeral PVC reclamation & `podd` ConnectRPC `List`/`Stat`/`Remove`.** Reclaimed ephemeral PVCs on `kill()` and implemented ConnectRPC `List`, `Stat`, and `Remove` handlers in `crates/podd` (`#68`).
- **Controller pod naming & image `ENV HOME` preservation.** Dropped the `-kata-pod` suffix in controller pod naming and preserved the container image's `ENV HOME` in `crates/podd` (`#72`).

## Before upgrading

`0.5.1` adds the `SandboxWebhook` CRD (`deploy/helm/cubepod/crds/cubepod.io_sandboxwebhooks.yaml`) and updates `PodBox` (`deploy/helm/cubepod/crds/cubepod.io_podboxes.yaml`). Apply the updated CRDs **before** running `helm upgrade`:

```bash
kubectl apply -f deploy/helm/cubepod/crds/
```

Upgrade gateway, controller, egress, and `podd` injector images together to `v0.5.1` via the [Kubernetes & Helm deployment guide](/deployment/kubernetes-helm/), and update client SDKs (`pip install -U cubepod==0.5.1` / `npm install cubepod@0.5.1`).
